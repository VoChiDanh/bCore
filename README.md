# bCore  [1.13.x - 1.18.x]

## Features

### Bank

> You can deposit/withdraw money to Bank

### Player Level / XP

> When you mine block you'll receive xp, when level up you'll get some rewards

### Lucky Chance

> With lucky chance you can get more power and xp when mine block

### Power

> When you are working, you'll lose power and when your power = 0, you can't do anything. So when you level up, max power will be upgrade to higher!

### Storage / Price

> You will have a virtual storage to storage listed blocks in config, when you mine block was listed in config, you'll get block to virtual storage. You can sell it!


### PvP System

> If you turn off PvP, you can't PvP with other Player..

### Weight

> When storage have any block, you weight will increase. When weight reach max. You can't mine anymore

### Custom Enchants

> Money - You'll get chance to get money when mining

## Commands

```
HELP_USER: 
/bCore info [Player] - Check info player
/Storage - Open sell gui
/Bank - Check money in bank
/Bank [deposit/withdraw] [number] - Deposit/Withdraw money to bank
```

```
HELP_ADMIN: 
/bCore plevel [add/set/remove] [Player] [Number] - Add/Set/Remove Player level
/bCore xp [add/set/remove] [Player] [Number] - Add/Set/Remove Player XP
/bCore power [add/set/remove] [Player] [Number] - Add/Set/Remove Player Power
/bCore glevel [add/set/remove] [Player] [Number] - Add/Set/Remove Gang Level
/bCore levelup [add/set/remove] [Player] [Number] - Add/Set/Remove Gang Points
/bCore maxpower [add/set/remove] [Player] [Number] - Add/Set/Remove Max Power
/bCore restorepower [add/set/remove] [Player] [Number] - Add/Set/Remove Restore Power
/bCore weight [add/set/remove] [Player] [Number] - Add/Set/Remove Weight
/bCore maxweight [add/set/remove] [Player] [Number] - Add/Set/Remove Max Weight
/bCore storage [add/set/remove] [Player] [Block Type] [Number] - Add/Set/Remove Storage
/bCore price [add/set/remove] [Block Type] [Number] - Add/Set/Remove Price
/bCore baseprice [add/set/remove] [Block Type] [Number] - Add/Set/Remove BasePrice
/bCore bankmoney [add/set/remove] [Player] [Number] - Add/Set/Remove Bank Money
/bCore bankmaxmoney [add/set/remove] [Player] [Number] - Add/Set/Remove Bank Max Money
/bCore reload - Reload config
```

## Permission

```
bCore.user - Permission for Player
bCore.admin - Permission for Admin
```
